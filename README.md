# Weighted Decision

Compare options against weighted criteria and see which one comes out ahead.

## Features

- Any number of options and criteria
- Weights from 1 to 5, scores from 0 to 5, result as a percentage
- A plain-language reading of the result, including when it is too close to call
- Copy the grid as a Markdown table

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

Everything is saved in the browser's local storage. No account, no API key, no server: nothing leaves your machine.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
